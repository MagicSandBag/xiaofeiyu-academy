# 小肥鱼学习平台 · 海底糖果设计语言 v1.2

> **代号**：海底糖果补习社 / Undersea Candy School  
> **适用**：DeepSeek Harness 插件「小肥鱼学习平台」——左侧「小肥鱼学堂」嵌入式主面板 + 右下角快捷浮层  
> **用户**：小学 1–6 年级孩子，以及查看学习情况的家长  
> **用途**：后续页面、组件、插画、动效、文案、验收的唯一视觉依据  
> **关键词**：厚描边、硬投影、奶油纸、深海蓝、贴纸角色、即时鼓励

---

## 1. 设计定位

### 1.1 一句话

**不是把成人学习 Dashboard 变可爱，而是把学习舱做成一张有生命的海底贴纸手账。**

孩子打开它时，应该先觉得“这里可以随便点一点”，再发现“点完真的能学会”。所以视觉上要**大胆、厚实、有手感**，信息上要**短、清楚、不吓人**。

### 1.2 视觉配方

```
奶油纸（约 62%） + 深海蓝骨架（约 22%） + 糖果色块（约 16%）
+ 一条蓝色大肥鱼（每屏 1 次主露出）
+ 2px 墨线 + 4–5px 实色投影
= 海底糖果补习社
```

### 1.3 六条设计原则

1. **先敢点，再学会**  
   按钮、选项、卡片都要有清晰的边界和按下去会“陷一下”的反馈。孩子不需要先理解设计规范，才知道哪里能点。

2. **一条鱼带路，不是一条鱼贴满**  
   小肥鱼是向导、同桌、情绪出口。每屏只保留 **1 个主 mascot**，其余位置用气泡、星星、小贴纸补情绪。

3. **把进步做成看得见的糖**  
   XP、金币、星星、饱饱度、连击，都是“努力有回音”。奖励要即时、具体、可积累；不做排名、不扣光、不用“前功尽弃”。

4. **奶油底上放彩色积木**  
   大面积保持奶油纸的安静，高饱和色只出现在按钮、图标砖、贴纸、进度条、重点卡。**颜色是积木，不是墙纸。**

5. **每屏只有一个主角**  
   首页的主角和「开始今天的闯关」，闯关页的主角是题目，成绩页的主角是星星。其余卡片自动退后半步。

6. **手作感 + 网格秩序**  
   贴纸可以歪 2–3°，气泡可以冒出来，但栅格、间距、字号、圆角必须严格。**活泼来自局部，不来自失控。**

### 1.4 非目标

- 不做“通用 SaaS 看板”的冷静灰蓝风。
- 不做玻璃拟态、霓虹渐变、3D 黏土、复杂拟物。
- 不做深色模式（本产品固定为奶油海底场景；未来若做，必须重新出 token，不要直接反色）。
- 不做排行榜、倒计时恐吓、断签惩罚、同伴横向比较。
- 不把 Emoji 当唯一功能语义；所有 Emoji 必须配文字或 `aria-label`。

## 2. 视觉母题

### 2.1 三种材质

| 材质 | 视觉表现 | 用在哪里 | 不要用在哪里 |
| --- | --- | --- | --- |
| **奶油纸** | `#FFF8E6` 底、细点阵、轻微暖色 | 学习舱底、空白区、阅读区 | 高饱和按钮内部 |
| **深海蓝** | `#1B2550 → #24336E` 渐变、白字 | 左侧导航、模态遮罩、主文字 | 大面积正文背景 |
| **糖果贴纸** | 珊瑚/鹅黄/薄荷/天蓝/丁香/粉，2px 墨线，实色投影 | CTA、图标砖、徽章、气泡、奖励 | 长文阅读背景、整页铺底 |

### 2.2 签名配方

任何“小肥鱼组件”至少满足其中两条：

1. **2px 墨线**：`border: 2px solid #1F2A5B`，不用 1px 灰线冒充。
2. **实色偏移投影**：`box-shadow: 0 4px 0 #1F2A5B`，不是柔和灰雾。
3. **大圆角**：卡片 23px，按钮 14px，胶囊 999px。
4. **贴纸倾斜**：贴纸/徽章允许 `rotate(-3deg ~ 3deg)`，正文和卡片不倾斜。
5. **奶油纸底**：任何白色卡片都放在奶油或海水浅底上，避免“白卡漂在白底”。

### 2.3 按压物理

```
默认：      0 4px 0 ink
悬停：      向上 2px，投影 6px
按下：      向下 2px，投影 2px
禁用：      不位移，降低透明度，保留轮廓
```

> 硬投影不是装饰，是“这个按钮可以被按下去”的承诺。**投影消失而组件还在动，是禁止的。**

## 3. 色彩架构

色彩分四层，从“永远不变”到“只在事件里出现”。

### 3.1 L0 奶油纸 · 结构层

| Token | 色值 | 用途 | 对奶油纸对比度 |
| --- | --- | --- | --- |
| `--xfe-ink` | `#1F2A5B` | 标题、墨线、主文字 | 12.9:1 ✔ AAA |
| `--xfe-ink-soft` | `#465184` | 正文、说明 | 7.2:1 ✔ AAA |
| `--xfe-ink-faint` | `#5F688C` | 占位、弱提示 | 5.2:1 ✔ AA |
| `--xfe-cream` | `#FFF8E6` | 学习舱底 | — |
| `--xfe-paper` | `#FFFDF7` | 卡片、面板 | — |
| `--xfe-sea` | `#F0FDFF` | 海水浅底 | — |
| `--xfe-sea-2` | `#E6F9F5` | 海水浅底 · 偏薄荷 | — |
| `--xfe-line` | `rgba(31,42,91,.16)` | 内部虚线、弱分割 | — |
| `--xfe-line-strong` | `rgba(31,42,91,.30)` | 输入框、强调分隔 | — |

**铁律**：奶油纸不是“米黄滤镜”。它要带一点暖、一点纸感，不能发灰；墨线必须够深，不能变成浅灰描边。

### 3.2 L1 深海骨架

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--xfe-navy` | `#1B2550` | 左侧导航、遮罩、最深文字 |
| `--xfe-navy-2` | `#24336E` | 导航渐变中段 |
| `--xfe-navy-3` | `#172047` | 导航渐变末端 |
| `--xfe-navy-soft` | `#2A3874` | 导航悬浮 |
| `--xfe-grad-rail` | `linear-gradient(180deg,#1B2550,#24336E 60%,#172047)` | 左侧导航 |

深海蓝是“秩序底座”：它让糖果色显得更亮，也把学习舱从聊天页面里切出来。**不要用纯黑 `#000` 代替。**

| `--xfe-mint-soft` | `#D9FAF1` | 薄荷浅底 | 正确反馈、成就 |
| `--xfe-mint-ink` | `#086B61` | 薄荷浅底上的文字 | 答对文案、掌握状态 |
| `--xfe-sky` | `#7BDDF2` | 海水高光 / 提示 | 头像光圈、提示卡 |
| `--xfe-sky-soft` | `#E7FBFF` | 天蓝浅底 | 提示、专注卡 |

| `--xfe-lilac-soft` | `#EFEAFF` | 丁香浅底 | 混合卡、成就 |
| `--xfe-pink` | `#FFB7D5` | 饱饱度 / 贴纸 | 饥饿条、庆祝 |

**面积配额**：

- 奶油 + 纸白 + 深海蓝 ≥ 80% 画面。
- 珊瑚实色 ≤ 10%，每屏只允许 **1 个珊瑚主 CTA**。
- 鹅黄/薄荷/天蓝/丁香/粉合计 ≤ 10%，用于小面积积木。
- 一屏内高饱和糖果色 **不超过 4 种**。

### 3.4 L3 学科色

| 学科 | 主色 | 浅底 | 描边/进度 | Token 前缀 |
| --- | --- | --- | --- | --- |
| 数学 | `#FF7A59` | `#FFE1D8` | `#FFB39E` | `--xfe-math` |
| 语文 | `#0AAFA0` | `#D3F7F1` | `#8EE2D8` | `--xfe-chinese` |
| 英语 | `#6E7BFF` | `#E4E6FF` | `#B8BEFF` | `--xfe-english` |

**用法**：只允许出现在 `42px 图标砖`、`3px 色条`、`小圆点`、`浅底`、`进度填充`。  
**禁止**：整张学科卡铺满主色；学科色不得替代状态色；学科色出现时必须同时有学科图标或中文字。

### 3.5 L4 状态色

| 状态 | Token | 填充 | 浅底 | 文字 |
| --- | --- | --- | --- | --- |
| 正确 / 掌握 | `--xfe-success` | `#0B8F81` | `#D9FAF1` | `#086B61` |
| 注意 / 待复习 | `--xfe-warning` | `#C69B19` | `#FFF3BF` | `#604B0C` |
| 错误 / 高风险 | `--xfe-danger` | `#D94B40` | `#FFE6E2` | `#A4332A` |
| 提示 / 信息 | `--xfe-info` | `#3D6FD8` | `#E4EEFF` | `#24479A` |

**三重编码**：颜色 + 形状/图标 + 文字。  
例：答对不能只变绿，必须同时出现 `✅ 答对啦！`；答错不能只变红，必须同时出现 `💧 差一点点` 和正确答案。色弱孩子也能读懂。

### 3.6 珊瑚上的文字

亮珊瑚 `#FF6F61` 配纯白小字对比度只有 2.7:1，**不用于 13px 小字**。

规则：

- 小字（≤16px）：用 `--xfe-on-coral` `#2A1420`，对比度 6.3:1 ✔。
- 需要白字：用 `--xfe-coral-deep` `#C43C31` 作底，白字 4.9:1 ✔。
- 亮珊瑚 + 白色只允许出现在 ≥24px 的展示字、插画和贴纸。

> 这条规则比“看起来亮”优先。孩子需要看清按钮上写的是什么。

### 3.7 渐变白名单

只允许这些地方出现渐变：

1. 左侧导航：`--xfe-grad-rail`
2. 首页 hero 卡：`--xfe-grad-hero`
3. 专注卡：`--xfe-grad-focus`
4. 冷知识卡：`--xfe-grad-tip`
5. 启动器/品牌块：`--xfe-grad-brand`
6. 进度条：`--xfe-grad-mint` / `--xfe-grad-hunger`

**禁止**：渐变文字、渐变描边、彩虹铺底、玻璃高光、彩色弥散阴影。

## 4. 字体与排版

### 4.1 字体栈

```css
--xfe-font-ui: "Nunito", "PingFang SC", "Hiragino Sans GB",
               "Microsoft YaHei", "Noto Sans SC", system-ui, sans-serif;
--xfe-font-number: "Nunito", "Inter", "PingFang SC",
                   "Microsoft YaHei", system-ui, sans-serif;
```

- 英文/数字优先 `Nunito`，中文回落到苹方/微软雅黑。
- 所有数字统计（XP、金币、正确率、倒计时）加 `font-variant-numeric: tabular-nums`。
- 不引入第二套中文字体，避免加载与风格分裂。

### 4.2 字重

| 角色 | 字重 | 说明 |
| --- | --- | --- |
| 大标题 / 题目 | `900` | 圆润、厚，像贴纸标题 |
| 卡片标题 / 按钮 | `900` | 保持“可按”的实体感 |
| 正文 / 说明 | `700` | 不用 400；低龄阅读更稳 |
| 数字 | `800–900` | 配合 `tabular-nums` |
| 弱提示 | `700` | 用颜色降级，不用细字重 |

### 4.3 字号阶梯

| 层级 | Token / 值 | 用途 | 行高 |
| --- | --- | --- | --- |
| Hero | `clamp(26px, 3.2vw, 42px)` | 首页问候、主标题 | 1.02 |
| Page H1 | `clamp(24px, 3vw, 34px)` | 闯关岛/错题礁标题 | 1.08 |
| H2 | `20px` | 区块标题 | 1.2 |
| Card Title | `16px` | 卡片标题 | 1.35 |
| Question | `clamp(21px, 2.5vw, 30px)` | 题目正文 | 1.42 |
| Body | `14px` | 正文、说明 | 1.6 |
| Body-sm | `12px` | 卡片副文、辅助说明 | 1.5 |
| Caption | `10px` | 标签、极短提示 | 1.4 |
| Answer | `15px` | 选项文字 | 1.45 |
| Number | `20–27px` | 统计数字 | 1.1 |

**可读性下限**：

- 面向孩子的**主阅读文本**不小于 14px；低年级建议 15–16px。
- `10px` 只用于极短标签，不用于句子。
- 选项文字 ≥ 15px；题干 ≥ 21px。
- 正文每行 22–30 个汉字；题干 12–20 个汉字；Hero 标题 8–14 个汉字。

### 4.4 排版禁止项

- 不用 300/400 细字重做正文。
- 不用全大写英文当标题（儿童识别慢）。
- 中文正文不加宽字距；只有 `kicker` 可用 `.12em`。
- 不用渐变文字、描边文字、投影文字。
- 不把长段落塞进 10–12px 的卡片说明里。

## 5. 间距、圆角、描边与阴影

### 5.1 间距

4px 基准，常用档位：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--xfe-sp-1` | 4px | 图标与文字 |
| `--xfe-sp-3` | 8px | 紧凑元素 |
| `--xfe-sp-5` | 12px | 卡内小间距 |
| `--xfe-sp-6` | 14px | 卡内标准间距 |
| `--xfe-sp-7` | 16px | 卡片内边距 |
| `--xfe-sp-8` | 18px | 卡片内边距（大） |
| `--xfe-sp-9` | 20px | 区块内边距 |
| `--xfe-sp-10` | 24px | 区块间距 |
| `--xfe-sp-12` | 32px | 页面底部留白 |

- 左栏 98px，右栏 302px，主区内边距 `20px 26px 32px`。
- 卡片与卡片 gap 10–16px；同一组卡片 gap 固定。
- 卡片最后一行到卡片下边缘 ≥ 10px，不允许贴边。

### 5.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `--xfe-r-xs` | 10px | 小图标、迷你标签 |
| `--xfe-r-sm` | 14px | 按钮、输入框 |
| `--xfe-r-md` | 18px | 导航项、小卡 |
| `--xfe-r-lg` | 23px | 标准卡片 |
| `--xfe-r-xl` | 26px | 大卡、嵌入式外壳 |
| `--xfe-r-2xl` | 34px | 学习舱外框 |
| `--xfe-r-full` | 999px | 胶囊、头像、环形 |

**不在七档里的圆角不再新增**。历史值 11/13/15/21/22/24 映射到最近档位；新组件只准用 token。

### 5.3 描边

| 场景 | 规格 |
| --- | --- |
| 学习舱外框 | 3px 墨线 |
| 标准卡片 / 按钮 / 胶囊 | 2px 墨线 |
| 内部弱分割 / 输入框 | 1.5px 墨线或 `--xfe-line` |
| 次级分组 | 2px dashed `--xfe-line` |
| 禁用 | 仍保留墨线，降低透明度，不使用无边框 |

### 5.4 阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `--xfe-shadow-hard-xs` | `0 2px 0 rgba(31,42,91,.20)` | 小按钮、quest |
| `--xfe-shadow-hard-sm` | `0 3px 0 rgba(31,42,91,.20)` | 小卡、chip、导航 |
| `--xfe-shadow-button` | `0 4px 0 #1F2A5B` | 标准按钮 |
| `--xfe-shadow-card` | `0 5px 0 rgba(31,42,91,.20)` | 标准卡片 |
| `--xfe-shadow-float` | `0 7px 0 #1F2A5B, 0 14px 28px rgba(13,24,60,.35)` | 启动器、浮层卡 |
| `--xfe-shadow-modal` | `0 16px 0 rgba(8,15,40,.38), 0 36px 90px rgba(4,10,30,.48)` | 模态学习舱 |

**禁止**：只用 1px 浅灰边框 + 大模糊阴影来制造层次；那会立刻变成“通用后台”。  
正确层次 = **墨线 + 实色投影 + 奶油底**。

## 6. 布局

### 6.1 学习舱骨架

```
┌──────────────────────────────────────────────────────────────┐
│  3px 墨线 · 34px 圆角 · 奶油纸                                │
│ ┌──────────┬────────────────────────────┬──────────────────┐ │
│ │ 左侧导航  │ 主内容                      │ 小肥鱼侧栏        │ │
│ │ 98px     │ minmax(0,1fr)              │ 302px            │ │
│ │ 深海蓝    │ 点阵奶油纸                  │ 海水渐变          │ │
│ │          │ 标题 / 卡片 / 题目           │ mascot / 任务     │ │
│ └──────────┴────────────────────────────┴──────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```

- 最大宽 `1260px`；高度 `min(870px, 100vh - 36px)`。
- 左侧导航固定 98px，深海蓝渐变，底部放等级小鱼头像。
- 右侧栏 302px，放 mascot、饱饱度、任务、指路；在窄容器隐藏。
- 主内容滚动，不整页滚动；侧栏独立滚动。
- 外框 3px 墨线 + 34px 圆角 + 双层硬投影。

### 6.2 两种入口，同一套视觉

| 入口 | 形态 | 容器 | 关闭方式 |
| --- | --- | --- | --- |
| 左侧「小肥鱼学堂」 | 嵌入主内容区的面板 | `main` slot，无遮罩 | 右上角 `↩` 返回对话 |
| 右下角小肥鱼 | 全屏浮层 | `shell.overlay` + 深蓝遮罩 | 右上角 `✕` / `Esc` / 点遮罩 |

两个入口共享数据；视觉上保持同一张“学习舱卡片”，只是浮层多了 `backdrop-filter: blur(9px)` 和深蓝遮罩。

### 6.3 常用内容栅格

| 页面 | 栅格 |
| --- | --- |
| 首页 Hero | `minmax(0,1.15fr) minmax(170px,.85fr)`，窄屏单列 |
| 首页主体 | `minmax(0,1.25fr) minmax(255px,.75fr)` |
| 学科入口 | 3 列 |

### 6.4 响应式与容器查询

| 条件 | 行为 |
| --- | --- |
| 视口 ≤ 1120px | 隐藏右侧栏，保留 92px 导航 + 主内容 |
| 视口 ≤ 920px | 首页/报告/成长改为单列；聊天侧栏收起 |
| 视口 ≤ 760px | 导航变成底部 6 项；主内容全宽；按钮 ≥ 44px |

```css
.xfe-embed {

@container xfe-embed (max-width: 1000px) {
  .xfe-app.is-embedded { grid-template-columns: 92px minmax(0, 1fr); }
  .xfe-app.is-embedded .xfe-side { display: none; }
}
```

### 7.8 闯关选项

## 9. 动效

### 9.1 三档

| 层级 | 时长 | 曲线 | 用途 |
| --- | --- | --- | --- |
| 微反馈 | 140ms | `ease-out` | 按钮按压、勾选、切换 |
| 界面转场 | 220ms | `cubic-bezier(.2,.8,.2,1)` | 弹层、卡片出现 |
| 庆祝 | 2600ms | `ease-out` | 完赛彩带、升级 |

### 9.2 常驻动效配额

- 每屏最多 **1 处**常驻动效：mascot 浮动/呼吸，或一个气泡。
- 同时运动的元素 ≤3 个。
- 浮动 4.2–5.2s，呼吸 4.4s，摇摆 2.4s。
- 除 mascot 外，卡片、按钮、文字不做无限动画。

### 9.3 庆祝

- 完赛：34 片彩带，2.6s 落下，不阻塞点击。
- 升级：Toast + 星星，不弹全屏。
- `prefers-reduced-motion` 时全部关闭，只保留即时状态变化。

## 10. 文案语气

### 10.1 三个特点

1. **短**：一句话说完，能用一个词不用两个。
2. **具体**：说“答对 8 题”，不说“表现优异”。
3. **不羞辱**：错题是“宝藏/贝壳/差一点点”，不是“又错了/太粗心/落后”。

### 10.2 词汇表

| 不说 | 要说 |
| --- | --- |
| 错误答案 | 差一点点 |
| 错题记录 | 错题礁的贝壳 |
| 连续打卡中断，前功尽弃 | 中断了 1 天，今天继续就好 |
| 你落后于 78% 的同学 | 你已经超过了自己的上周 |
| 正确率仅 42%，很差 | 42% 已掌握，还有 8 个知识点可以突破 |
| 学习任务 | 今日任务 / 今日冒险 |
| 开始测试 | 开始闯关 |
| 暂无数据 | 这片海还没被你探索过 |
| 你很聪明 | 你刚才的步骤很清楚 |

### 10.3 微文案示例

- 答对：`哇！这题被你一口吞掉啦！`
- 答错：`咕噜～错题也是宝藏，先收进错题礁。`
- 空错题：`错题礁空空的，去闯关岛捡几道题吧！`
- 专注完成：`专注完成，奖励已入账。`
- 喂食：`小肥鱼吃得肚皮圆圆。`
- 休息：`先喝口水，伸个懒腰，再回来。`

## 11. 数据可视化

### 11.1 图表选型

| 问题 | 用 | 不用 |
| --- | --- | --- |
| 最近 7 天学得怎么样 | 7 柱条形图 + 直接数值 | 雷达图、3D 柱、双轴 |
| 三科正确率 | 水平条形 + 百分比 | 饼图、环形多值 |
| 累计统计 | 4 个数字卡 | 仪表盘 |
| 连续天数 | 大数字 + 火苗 + 小标签 | 打卡日历墙 |

### 11.2 规格

- 7 天柱状图：柱宽 ≤28px，从 0 开始，最多 7 根，今天用鹅黄→珊瑚高亮。
- 直接标注数值（9px/900），不依赖图例。
- 水平学科条：学科色填充，右侧 `正确率 · 题量`。
- 图表容器：2px 墨线、23px 圆角、纸白底、18px 内边距。
- 网格线只允许 1px 虚线、≤4 条；不用渐变填充、阴影、3D。
- 每个图表必须有 `aria-label` 和文本摘要。

### 11.3 语气

数据是“看见自己”，不是“审判自己”。  
“最近 7 天一共答了 24 道题”优于“你只完成了 60%”。

## 12. 无障碍与未成年人保护

### 12.1 基线

- 正文对比度 ≥4.5:1；大号标题 ≥3:1；UI 描边 ≥3:1。
- 触控目标 ≥44×44px，儿童主按钮建议 48px。
- 所有图标按钮必须有 `aria-label` / `title`。
- 弹层 `role="dialog"` / `aria-modal="true"`，`Esc` 可关，关闭按钮自动聚焦。
- 键盘可达；焦点环 3px 珊瑚色。
- 支持 200% 字号不破版。
- `prefers-reduced-motion` 关闭浮动、摇摆、彩带。
- 不依赖颜色传达对错；颜色 + 图标 + 文字三重编码。

### 12.2 未成年人保护

- 不做排行榜、同伴横向比较、公开姓名/头像。
- 不用红色倒计时制造焦虑；默认不显示计时。
- 不做断签惩罚、不清零、不说“前功尽弃”。
- 不做夜间推送；学习数据只存本机 `localStorage`。
- 默认不联网；拍照识题是唯一可选的模型调用，必须由用户点击“让小肥鱼识题”才发生，并明确提示会调用当前模型一次。PDF 目录在浏览器本地解析，不上传原文件。
- 超纲问题由孩子主动复制去问 DeepSeek；平台不自动上传学习内容。
- 家长设置可重置进度、关闭音效；重置需二次确认。

## 13. 落地与继承

### 13.1 文件

```
设计语言/
├─ xiaofeiyu-design-spec.md      ← 本文件，规则与决策
├─ xiaofeiyu-design-tokens.css   ← token + 最小 primitives
└─ xiaofeiyu-design-guide.html   ← 可视化验收页
```

运行时组件样式仍在 `client.js`；token 文件是新增页面的**唯一颜色/圆角/阴影来源**。

### 13.2 引入

```html
<link rel="stylesheet" href="./xiaofeiyu-design-tokens.css">
```

```css
.my-card {
  background: var(--xfe-paper);
  border: var(--xfe-border);
  border-radius: var(--xfe-r-lg);
  box-shadow: var(--xfe-shadow-card);
}
```

### 13.3 命名

- 所有组件类以 `xfe-` 开头，避免污染宿主。
- 变体用 `is-*`：`is-primary` / `is-sun` / `is-mint` / `is-ghost` / `is-sm`。
- 状态类用 `is-correct` / `is-wrong` / `is-dim` / `is-active`。
- 不新增无前缀的全局类；不覆盖宿主 `button`、`input`、`body`。

### 13.4 新组件接入清单

1. 颜色是否都能映射到 token？
2. 圆角是否在 10/14/18/23/26/34/999 七档内？
3. 是否使用 2px 墨线 + 硬投影？
4. 有没有超过 1 个珊瑚主 CTA？
5. 贴纸/装饰是否 ≤3 处？
6. 触控区是否 ≥44px？
7. 是否有文字/图标双编码？
8. 窄容器是否用 container query 处理？
9. 是否响应 `prefers-reduced-motion`？
10. 空态/加载/错误是否都有文案？

### 13.5 与现有实现的关系

- `client.js` 是当前运行时；本规范是后续迭代的基线。
- 如 token 与运行时硬编码冲突，**以 token 为准**，逐步替换；不要在新组件里复制旧硬编码。
- 图标/插画可继续使用 Emoji 贴纸，但必须配文字或 `aria-label`；核心导航建议逐步换 SVG。

- [ ] 奖励具体到 XP/金币/星星
- [ ] 空态不是“暂无数据”

### 无障碍
- [ ] 触控 ≥44px
- [ ] 图标按钮有 aria-label
- [ ] 弹层可 Esc 关闭
- [ ] 对比度达标
- [ ] 颜色不是唯一信息通道

## 16. 扩展模块（v1.1）

这些模块是 v1.1 新增，但视觉语言不另起一套。它们只复用既有 token 和组件规则。

### 16.1 教材库

- 入口：左侧导航新增 `📚 教材库`，与闯关岛同级。
- 内置目录只是示例；家长可上传任何版本 PDF。上传过的教材进入“我的教材架”，同一学科/年级/册次可随时切换；不要写成“只能用人教版”。
- 目录解析分三路：文字层 + 版面坐标自动解析；扫描版选目录页后交当前模型识别；手动粘贴/只保存档案。不得静默用示例目录替代用户教材。
- “让小肥鱼读目录”要明确写出“会调用当前模型一次、最多 6 页”，并显示目录页范围；失败时保留粘贴和只保存档案，不把错误目录写进教材。
- 结构：学科 tabs → 年级/册次 → 当前教材卡 → 单元手风琴 → 知识点胶囊。
- 单元展开用 27px 方形序号 + 12px/900 标题 + 9px 知识点数；知识点胶囊 999px、1.5px 描边。
- 知识点详情用 600px 弹层：书名 kicker、知识点标题、学科/年级/单元标签、`小肥鱼划重点` 虚线块、关联错题、两个动作（问小肥鱼 / 练这个知识点）。
- PDF 导入弹层：700px，最多 700px 高；目录预览可滚动；`只解析目录，PDF 原文件不上传、不写入浏览器存储` 必须可见。

### 16.2 拍照收录

- 700px 弹层；图片预览最大高 160px；「让小肥鱼识题」是珊瑚主按钮，旁边保留「换一张」幽灵按钮。
- 必填：题目 + 正确答案；孩子答案、错因、知识点可后补。
- 识题调用当前模型一次，必须明示；模型不支持图片时降级为手动表单，不报错退出。
- 保存后进入错题礁，带 `📷 拍照收录` 标签；储存的是 420px 缩略图，不存原图。
- 底栏操作 sticky 在弹层底部，长表单滚动时始终可保存。

### 16.3 变式掌握

- 变式弹层复用闯关选项：15px 选项、字母块、正确薄荷/错误珊瑚。
- 顶部显示 `第 N 次变式`、`掌握进度 0/2`、知识点标签。
- 答错：掌握进度归零，显示正确答案和讲解，按钮「再来一道变式」。
- 答对：进度 +1；连续 2 次答对才显示「掌握啦！错题变成知识贝壳」。
- 掌握后错题移除，知识贝壳 +1，小肥鱼日记 +1；不在错题礁留“已掌握”的堆积。

### 16.4 学情报告

- 范围：最近 7 天 / 30 天 / 本学期 / 自定义；自定义至少 7 天。
- 采用 760px 可打印弹层：顶部孩子+范围、4 个统计卡、学科条、重点知识点、小肥鱼建议。
- 打印用独立窗口，不打印宿主界面；复制使用纯文本版本。
- 文案只做纵向自我对比；不出现排名、同伴比较、红色倒计时。

### 16.5 知识贝壳与小肥鱼日记

- 1 道错题被掌握 = 1 枚知识贝壳；贝壳不是货币，不可消费，只作为“掌握证据”。
- 日记最多 24 条，记录教材上架、拍照收录、变式掌握、闯关完成等事件；侧栏小肥鱼会引用最近一条日记。
- 日记行：22px emoji 方块 + 10px/700 文本 + 8px 日期；不使用时间线、社交 feed 或点赞。

### 16.6 个人学习档案

- 入口是 header 左侧的胶囊头像 + 昵称 + `▾`，不新增第 8 个导航项；移动端只保留 25px 头像。
- 档案弹层 640px：孩子行 = 40px 头像 + 昵称 + 年级/Lv/题量/正确率 + 待复习/贝壳；当前孩子用薄荷底和“正在学”。
- 添加孩子：昵称、年级、8 个 emoji 头像；最多 6 个。删除只对非当前孩子开放，需要点两次确认。
- 头像选择必须“选没选上”一眼可见：42px 方块，选中项薄荷底 + 墨色描边 + 右上角珊瑚色 ✓ + 轻微上浮；下方固定显示“已选择 ×××”，不能只靠边框颜色。
- 每个孩子的 XP、金币、饱饱度、错题、日记、贝壳、装扮独立；教材库和音效设置共享。
- 切换时先保存当前快照，再加载目标快照；不在当前档案的根数据上做任何混合。

### 16.7 数学排版

- 小朋友看到的界面里不允许出现 LaTeX 源码：`\frac{7}{6}`、`\times`、`\div`、`$...$` 都必须先被清理。
- 存档/输入层可以写 `7/6`；展示层必须由 `MathText` 画成上下两行的真分数：分子、1.8px 分数线、分母。
- 复杂分子/分母用 `(3x+3)/(6)` 存档，展示时仍画成上下结构；不把 `(3x+3)/6` 误读成只有 `3/6` 是分数。
- 除法符号 `÷` 是合法小学符号，不强制改成 `/`；只有等号右边明确是分数答案时，才把 `x=7÷6` 规范成 `x=7/6`。
- 分数行高会增加，选项、错题卡、聊天气泡必须允许上下结构自然撑开，不裁切分子/分母。

### 16.8 悬浮入口与全屏比例

- 右下角小肥鱼是 `84px` 按钮（移动端 `66px`），初始距底边分别为 `92px` / `82px`。
- 按住头像可拖到屏幕任意位置，位置写入 `localStorage`；拖动超过 4px 不触发打开，普通点击才打开。
- 全屏浮层在超大屏（≥2200px）上下留约 10%（`padding: 10vh 2vw`），中小屏用 4vh 接近满屏；最大宽 `2100px`；视口高度不足 900px 时改为 12px 边距，优先保证清晰。
- 宽屏（≥1500px）自动放大标题、正文、按钮和卡片间距；全屏不是把 1260px 的画布硬拉大，而是用更清晰的字号和更松的块间距。
- 任何情况下正文不小于 12px，答题选项不小于 15px，按钮不小于 11px；不用“缩小整体界面”来塞内容。

01

设计定位

先敢点，再学会

小肥鱼学习平台不是“把成人学习看板变可爱”。它更像孩子课桌抽屉里那本贴满贴纸的练习册： 打开时有颜色、有角色、有声音；真正学习时，题目和进度又足够清楚，不抢戏。

👆
先敢点

2px 墨线 + 4px 实色投影 + 明确的按压缩放，让孩子一眼知道哪里能点。

🐟
一条鱼带路

小肥鱼是同桌和向导，每屏只主露出一次；其余用气泡、星星、贴纸补情绪。

🪙
进步看得见

答对立刻有 XP、金币、连击和一句具体夸奖；不排名、不扣光、不羞辱。

一句话配方：奶油纸 62% + 深海蓝 22% + 糖果色 16% + 一条大肥鱼 + 2px 墨线 / 4–5px 硬投影。

无障碍与未成年人保护

每个孩子都能看清、点到、读懂
基线
正文 ≥4.5:1；标题 ≥3:1；UI 描边 ≥3:1
触控 ≥44px，儿童主按钮建议 48px
图标按钮必须有 aria-label / title
弹层 role=dialog、Esc 关闭、关闭按钮聚焦
颜色 + 图标 + 文字三重编码
prefers-reduced-motion 关闭无限动画
保护
不排名、不横向比较、不公开姓名/头像
不做断签惩罚、不清零、不恐吓倒计时
数据只存本机 localStorage，不联网
默认不调用模型；拍照识题需主动点击，调用一次
夜间不推送；家长可重置进度、关音效

15

落地：Token 用法

新页面只消费 token，不复制硬编码

引入 xiaofeiyu-design-tokens.css，所有新组件从变量出发。

/* 一个标准糖果卡片 */
.xfe-my-card {
  background: var(--xfe-paper);
  border: var(--xfe-border);
  border-radius: var(--xfe-r-lg);
  box-shadow: var(--xfe-shadow-card);
  padding: var(--xfe-sp-8);
}

/* 珊瑚上的小字：不要纯白 */
.xfe-my-cta {
  background: var(--xfe-coral);
  color: var(--xfe-on-coral);
  border: var(--xfe-border);
  box-shadow: var(--xfe-shadow-button);
}
命名：组件类以 xfe- 开头；变体用 is-primary / is-sun / is-mint / is-ghost / is-sm；状态用 is-correct / is-wrong / is-active。不覆盖宿主 button/input/body。

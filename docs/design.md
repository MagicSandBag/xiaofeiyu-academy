# 小肥鱼学习平台 · 设计说明

> 视觉与组件规范见 [海底糖果设计语言 v1.0](../设计语言/xiaofeiyu-design-spec.md)；可视化导览见 [design guide](../设计语言/xiaofeiyu-design-guide.html)。

## 为什么做

把 DeepSeek Harness 里那只蓝色大肥鱼从“陪聊桌宠”变成“会陪学的同桌”：孩子打开学习舱，就能选年级、闯关、看讲解、整理错题、喂养小肥鱼、看自己的学习报告。所有进度留在本机浏览器里，不需要账号。

## 体验目标

- **一眼就想点**：左侧边栏新增“小肥鱼学堂”入口，右下角还留着一只探头的小肥鱼；两处都能进入奶油色 + 珊瑚橙 + 海水蓝的“海底糖果补习社”。
- **两种打开方式**：左侧入口把学习舱嵌进主内容区，适合连续学习；右下角浮层随时弹出，适合从对话里快速看一眼。两者共用同一份进度。
- **三分钟一小关**：每关 4–7 题，答完立刻有星星、金币和夸张的鼓励，不给孩子长时间等待。
- **错了也有安全感**：错题自动进“错题礁”，用小肥鱼的口吻讲思路；换数字/问法连续答对 2 次，或家长确认“我懂了”，才收进知识贝壳。
- **学习能变成养成**：答对攒 XP 和金币，喂小鱼干、买学士帽/墨镜/泳圈，等级和饥饿度都有反馈。
- **家长看得到**：成绩单给出 7 天柱状图、正确率、学科强弱项和一句学习建议。

## 功能

1. **学习舱首页**：问候、每日任务、学科入口、专注计时、今日冷知识。
2. **闯关岛**：数学（按年级动态出题）、语文、英语、混合模式；轻松/标准/挑战三档。
3. **小肥鱼答疑**：安全算式求解 + 分步讲解 + 知识点卡片 + 出题；超纲问题可一键复制去问 DeepSeek。
4. **错题礁**：按学科筛选，显示你的答案、正确答案和讲解；支持练习错题、拍照收录、变式再练，掌握后移除。
5. **教材库**：内置示例目录；家长可上传任何版本 PDF 自动提取目录；知识点可关联错题、直接练习或问小肥鱼。
6. **成长湾**：等级、XP、饱饱度、6 种零食、6 件装扮、12 个成就、知识贝壳和小肥鱼日记。
7. **成绩单**：最近 7 天/30 天/本学期/自定义日期；生成可打印、可复制的学情报告。
8. **学习档案**：顶部头像切换孩子；每个孩子独立进度、错题、贝壳和日记；教材库共享。
9. **家长设置**：昵称、年级、音效、重置进度。

## 教材目录导入

教材 PDF 不能假设都有文字层。现在按三路降级：

1. 文字层 + 版面坐标：自动识别目录页、按字号/位置还原单元（人教版实测可提取 7 个单元）。
2. 扫描版/双栏：把用户指定的目录页渲染成图片，调用当前模型一次做目录识别；不发送整本 PDF。
3. 手动粘贴目录，或只保存教材档案；绝不静默把内置示例目录套到别的版本上。

## 入口与全屏

右下角小肥鱼可拖拽并记住位置；全屏浮层在超大屏上下留约 10%，中小屏接近满屏并放大字号与块间距，视口高度不足 900px 时优先保证清晰。全屏不是简单拉大画布，而是优先保证正文、选项和按钮清晰可见。

## 技术

- 一个 DSH bundle：宿主半边注册 `/xiaofeiyu-academy/assets/*` 静态资源；浏览器半边注册三个座位：
  - `sidebar.panellist`：左侧“小肥鱼学堂”入口
  - `main`：左侧入口打开的嵌入式学习舱
  - `shell.overlay`：右下角快捷浮层
- 两个学习舱实例共享一个模块级 store，避免同一页面里的进度分叉；嵌入式界面用容器查询适配主内容区的窄宽度。
- 纯 React + 原生 CSS；PDF.js 随包用于本地目录解析，无外部 CDN。
- 状态存 `localStorage`，键为 `xiaofeiyu-academy:v1`。
- 题目引擎全部本地生成/本地题库，数学题按 1–6 年级难度动态生成。
- 视觉资源复用本机 `dsh-pet` 的小肥鱼形象；另绘制 SVG 鱼作为加载失败兜底。

## 非目标

- 不做账号、云同步、家长端远程监控。
- 不替代学校课程，不覆盖完整教材。
- 默认不调用模型；拍照识题需要用户主动点击，调用当前模型一次，模型不支持图片时退回手动填写。
